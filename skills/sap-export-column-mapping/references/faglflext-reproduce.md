# 实战二：从 FAGLFLEXT 原始导出复现自建总账报表

> 主册：[`../SKILL.md`](../SKILL.md)。整表导出（40k 行 × 122 列）怎么定位列、怎么定符号、怎么校准。
> 记住两条：**中文表头是重复的，只能按 0 基序号定位**；**HSL 已带借贷符号，不要再按 DRCRK 翻转**。

场景：财务/业务导出整张 `FAGLFLEXT`（新总账**总计表**，40k 行 × 122 列），要复现某个自建总账报表（如 ZFIR007B MS 报表）的口径，或反查报表数字出处。

## 1. 过滤条件从源码抄，不要自创

ZFIR007B 的 `START-OF-SELECTION`：

```abap
SELECT ryear drcrk rpmax rtcur racct rbukrs rfarea
       hslvt hsl01 ... hsl16
  INTO CORRESPONDING FIELDS OF TABLE it_itab
  FROM faglflext
  WHERE ryear  = p_year     " 2026
     AND rldnr  = p_rldnr   " '0L'
     AND rrcty  = '0'
     AND rbukrs = p_bukrs   " 'LNT'
     AND prctr IN s_prctr.  " 通常为空 = 不限
```

导出后先 `Counter` 一遍 `RYEAR/RLDNR/RRCTY/RVERS/RBUKRS`，确认导出没夹带别的期间或分类账。

## 2. 列定位：中文表头是**重复**的，只能按序号

FAGLFLEXT 的表头有 16 个一模一样的「本位币中的业务总计」，按名字找必然错位。**必须按 0 基序号定位**：

| 序号 | 字段 |
|---|---|
| 0 | RYEAR |
| 1–9 | OBJNR00–OBJNR08（9 个对象编号，常全 0） |
| 10 / 11 | DRCRK 借贷标识 / RPMAX 期间 |
| 21 / 23 | RACCT 科目 / RBUKRS 公司代码 |
| 16 / 17 / 18 / 19 | RPROC 参考过程 / RLDNR / RRCTY / RVERS |
| 36 | TSLVT |
| 37–52 | TSL01–TSL16 |
| **53** | **HSLVT 年初结转** |
| **54–69** | **HSL01–HSL16 本位币各期发生额 ← 自建报表通常用这组** |
| 70–86 / 87–103 / 104–120 | KSL / OSL / MSL 组 |
| 121 | TIMESTAMP |

Excel 列号 = 序号 + 1。所以 **HSL09 在 0 基索引 62 / Excel 第 63 列**。

## 3. 符号规则

- **HSL 本身已带借贷符号**（借方正、贷方负），**不要再按 DRCRK 翻转**。DRCRK 只表示该记录的净方向，不参与金额符号。
- 配置表（如 ZTFI003B）里项目级的**「贷方标记」= 'X'** 时，取数结果整体乘 −1：

```abap
IF conf-zfisign = 'X'.
  <fs1> = <fs1> - <fs>.     " 即累加后取反
ELSE.
  ADD <fs> TO <fs1>.
ENDIF.
```

实测：项目70（贷方标记 X，科目 0078010300-0078010999）原始合计 `−120,105.52` → 取反 `+120,105.52`，与报表一致。

## 4. 校准：拿报表的已知项目值来对撞（同「四步配方」）

用导出数据按 `RACCT` 区间求和，去碰报表上已知的项目金额；**逐位相等才算列定位正确**：

```
项目2 科目 0071010101-0071010111  HSL09 求和 = 259,136,630.70  vs 报表 259,136,630.70 ✔
项目16 科目 0072 段                HSL09 求和 =   5,270,029.17  vs 报表   5,270,029.17 ✔
项目25 科目 0073 段                HSL09 求和 =   6,534,954.56  vs 报表   6,534,954.56 ✔
项目70 科目 0078010300-0078010999  HSL09 求和 =    −120,105.52 取反 = +120,105.52 ✔
```

再加一条**年度累计**的独立确认：`Σ(HSL01..HSL09) = 2,215,148,560.93` = 报表「年度累计发生额」逐位相同。

一次校准 4/4 全中，说明列偏移 + 符号规则都对；有一处不对，优先怀疑列偏移。

## 5. 已知边界

- **FAGLFLEXT 是汇总表，不含科目名称、不含行项目**。要科目描述得导 `SKAT`/`SKA1`；要凭证明细得上 `ACDOCA` 或 `FAGLL03H`。
- `RACCT` 在 Excel 里会掉前导零（`0071010101` → `71010101`），比较前必须 `str(int(v)).zfill(10)`。
- 同一段里常有多个「镜像」科目对（如 `0071010101` ↔ `0012130309`，`0045010101` ↔ `0012010309`，`0078010101/0078010501` ↔ 项目63），数值逐月相等、符号相反；不要把它们当成两笔业务。
- 靠「逐笔找某个差额值」很可能找不到：本例 198,279.01 既不是任何 `(科目 × 期间)` 的发生额，也不是任何两科目之差（穷举 304 科目 × 两两 = 4.6 万组全落空）。**这时不要停在「无法隔离」上——先做下面的「实战三」把差异定位到某一侧，再索要对应的凭证明细。**
