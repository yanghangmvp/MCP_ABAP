# 实战五：怎么把 ACDOCA 行项目明细导出来（给用户的操作指引）

> 主册：[`../SKILL.md`](../SKILL.md)。**先把目标段的应有金额算出来给对方当锚**，再给筛选条件模板，
> 否则对方导回来你还得再对一轮。

需要核对某段科目、但手上只有 FAGLFLEXT 总计表时，就得让用户补导**行项目明细**。给指引时套下面模板，别让用户自己猜。

## 1. 先认「用户手上那份明细是怎么导的」

SAP GUI 从 ALV 报表用「系统 → 列表 → 导出 → 本地文件 → 电子表格」导出的文件，特征是：

- 扩展名 `.XLS`，实际是 **GBK 编码 + Tab 分隔纯文本**（`file` 报 ISO-8859 text）
- 表头是**中英文对照 + 技术字段名**，如 `总账 (HKONT)`、`凭证抬头文本 (BKTXT)`、`抵销科目 (GKONT)`、`期间 (FISCPER)`

认出这个后，**最省事的指引 = 让用户复用同一入口/报表，只改筛选条件**，不用教他走新事物码。

## 2. 两套入口，按用户工具能力给

| 方案 | 入口 | 适用 |
|---|---|---|
| A（首选，最省事） | 复用用户上次导明细的**同一个报表/入口**，只把「总账科目」从单值改成**区间** | 该入口支持科目区间时 |
| B（通用兜底） | `SE16N` → 表 `ACDOCA` → 按条件筛选后导出 | 入口不支持区间、或用户想直查 |

FAGLL03H / FAGLL03（总账行项目）同样能按科目区间+期间出明细，字段够用。

## 3. 筛选条件模板（直接抄）

```
RLDNR   = 0L              账
RBUKRS  = <公司代码>       如 LNT
GJAHR   = <年>             如 2026
FISCPER = <YYYY.0MM>      如 2026.009    （或 POPER = 9）
RACCT   = <科目下限>–<科目上限>   用「多项选择 → 区间」
```

**★ 前导零坑**：工具里填 8 位（`7200000–7399999`）若查不到数据，改 10 位（`0072000000–0073999999`）。ACDOCA 的 `RACCT` 是 CHAR10，`7200000` 会被补成 `0007200000`，与 `0072000000` 不是一回事。

**一次导多段**：若工具支持，把区间开大（如 `0072000000–0073999999` 一次覆盖 0072+0073），导出后按科目前 4 位在本地拆，少操作一轮。

## 4. 必须勾的输出字段（定位「漏收」的关键）

- `BELNR` 凭证号 · `HKONT` 科目 · `SHKZG` 借贷标 · `CURRVAL_10` 公司代码货币值（↔ HSL）
- `BKTXT` 凭证抬头 · `SGTXT` 行项目文本 —— 找业务性质
- `GKONT` 抵销科目 —— 还原内部对转，**这条最有价值**
- `TCODE` · `USNAM` · `BUDAT` · `BLART`

## 5. 交付前先算好「基准金额」给用户当锚

别只说"你去导"。**先把目标段在 FAGLFLEXT 里的应有金额算出来**告诉用户：他导完能立刻自查，你拿到也能立刻对撞。

```
0072 人工段   9月 = 5,270,029.17   (16 个科目)
0073 制造费段 9月 = 6,534,954.56   (33 个科目)
两段合计          = 11,804,983.73
```

（逐月也一起给，便于判断"是不是只有某月异常"。）

## 6. 顺手把「未来要用的段」一并索要

定位一个缺口往往要查多个段。给指引时直接列全，省一次来回：
