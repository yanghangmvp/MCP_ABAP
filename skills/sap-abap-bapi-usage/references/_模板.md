## 1. 用哪个（选型）

| 需求 | 走什么 | 理由 |
|---|---|---|

写清**不要用什么**，以及为什么（这是最有价值的部分——防止下一个人重走弯路）。

## 2. 签名（关键形参）

只列真正要填的，标注类型与长度限制：

```
PARAM_A   I   <类型>   " 说明
ITEMS     T   <结构>   " 每行必带 xxx
RETURN    E   BAPIRET2
```

## 3. 必填与配对（缺了会怎样）

- **`x` 结构**：改哪些字段就要在 `*X` 结构里置 X。
- **标识结构**：数据元素必须是 `CHAR1`，不能是 `BAPIUPDATE`。
- **成对表**：行数必须一致、键必须逐行相同。
- **字段长度**：哪几个字段会静默右截断。

## 4. 坑（现象 → 根因 → 解法）

| 现象 | 根因 | 解法 |
|---|---|---|

一条一行。**这是本文件最有用的部分**，以后每次踩到就补一行。

## 5. 对账点

| 检查项 | 表 / 字段 | 期望值 |
|---|---|---|

不要写「返回 S 即成功」，写**表 + 字段 + 期望值**。
