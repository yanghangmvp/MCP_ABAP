# 40 · PP 生产订单

> 分册归属：`sap-abap-bapi-usage`。覆盖技术完成、取消技术完成、用户状态、状态批量判定。
> 报表侧怎么组织取数与 ALV 展示见 `sap-abap-prog-push-run` §10。

## 1. 批量技术完成 → `BAPI_PRODORD_COMPLETE_TECH`

**不要用** `BAPI_ALM_ORDER_MAINTAIN` + `it_methods` —— 那是跨对象维护用的，要手工拼 `refnumber`/`objecttype`/`objectkey`，且语义不是 TECO。

签名（`fupararef` 实测）：

```
ORDERS             T   BAPI_ORDER_KEY          " 字段 ORDER_NUMBER，可多张
DETAIL_RETURN      T   BAPI_ORDER_RETURN
RETURN             E   BAPIRET2
SCOPE_COMPL_TECH   I   BAPI_ORDER_FUNC_CNTRL-SCOPE_COMPL_TECH
```

```abap
ls_scope-scope_compl_tech = 'X'.
CALL FUNCTION 'BAPI_PRODORD_COMPLETE_TECH'
  EXPORTING scope_compl_tech = ls_scope
  TABLES    orders           = lt_orders
            detail_return    = lt_detail
            return           = lt_ret.

READ TABLE lt_ret TRANSPORTING NO FIELDS WITH KEY type = 'E'.
IF sy-subrc = 0.
  CALL FUNCTION 'BAPI_TRANSACTION_ROLLBACK'.
ELSE.
  CALL FUNCTION 'BAPI_TRANSACTION_COMMIT' EXPORTING wait = 'X'.
ENDIF.
```

**该 BAPI 没有「技术完成日期」入参** —— 要指定日期只能成功后另补 `UPDATE aufk SET idat2 = ...`，或走 BAdI（直改标准表要评估审计与权限风险）。

## 2. 取消技术完成 → 没有标准 BAPI

实测 `SELECT funcname FROM enlfdir WHERE funcname LIKE 'BAPI_PRODORD%'`：34 个函数里有 `COMPLETE_TECH` / `CLOSE` / `SETUSERSTATUS` / `REVOKEUSERSTATUS` / `SET_DELETION_FLAG`，**无 TECO Reset**。

`IBAPI_ALM_ORDER_TECO_RESET` 是内部函数，不当正式方案。

只能 BDC 调 `CO02`：屏幕 `SAPLCOKO1`，功能码 `=ENTK`，**必须先 `SELECT` 原值再回填**，否则必输字段被清空而报错。

## 3. 用户状态（财务关闭标识等）

- `BAPI_PRODORD_SETUSERSTATUS` / `BAPI_PRODORD_REVOKEUSERSTATUS` 是官方接口。
- `STATUS_CHANGE_EXTERN` 亦可用：`user_status` 传状态码（如 `E0002`）、`set_chgkz = 'X'`。
- 用户状态码是**项目自定义的**（`TJ30`），不要照抄别项目的 `E0002`，先查 `TJ30T`。

## 4. 状态判定别逐单查

一次取全，再内存切片：

```abap
SELECT j~objnr, t~txt04
  FROM jest AS j
  JOIN tj02t AS t ON t~stsma = @space AND t~stat = j~stat AND t~spras = @sy-langu
  INTO TABLE @DATA(lt_stat)
  WHERE j~inact = @space.
SORT lt_stat BY objnr.
```

按订单 `objnr` 二分/切片遍历，别在循环里 `SELECT SINGLE`。
系统状态码：`I0045` = TECO，`I0046` = 关闭，`I0002` = 已释放。

## 5. 对账点

| 检查项 | 表 / 字段 |
|---|---|
| 技术完成已置 | `AUFK-IDAT2` 非空；`JEST` 出现 `I0045` 且 `INACT` 为空 |
| 用户状态 | `JEST` + `TJ30T` 确认自定义状态码 |
| 订单未被锁 | `AUFK-OBJNR` 的 `JEST` 无 `I0048`（锁定） |

**批量前先用 1 张单跑通并立即对账**，再扩到全量——批量 TECO 出错不会回滚已完成的单。
