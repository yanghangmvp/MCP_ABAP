# 20 · 语言与数据格式

> 分册归属：`sap-abap-bapi-usage`。**任何域都会踩**：语言决定文本能不能读到，格式决定值进不进得去。

## 1. ★ BAPI 取文本用的是「会话语言」

- **BAPI 取主数据文本用的是会话语言，不是你代码里的任何变量。**
- **`SET LOCALE LANGUAGE '1'.` / `sy-langu = '1'.` 都改不动它**（实测两法皆无效）。唯一有效入口是**会话级请求头 `sap-language`**（ADT 场景即 `SAP_LANGUAGE_OVERRIDE`），在 ABAP 代码之前生效。
- 典型症状：`BAPI_SALESORDER_CREATEFROMDAT2` 在无头英文会话下返回 `V2 157 Missing text for division 10 language EN`，但人工 ZH 登录跑同一单正常。
- 与 `T100` 消息文本是同一类根因：**SAP 的文本读取语言 = 会话语言，不 fallback**。写消息要双语言，建主数据文本同样要双语言。
- **根治只能靠主数据**：接口若由外系统以英文 RFC 调用，必须请顾问补齐 `TSPAT` 等文本表的 EN，代码绕不过去。
- 验文本元素同理：无头跑必须带 `SAP_LANGUAGE_OVERRIDE=zh`，否则 ZH-only 文本池读空会误判成「文本没推上去」。

## 2. 编码补零：`ALPHA = IN`，但 `MATNR` 是反例

- 客户 / 供应商 / 科目 / 成本中心 / 订单号一律 `ALPHA = IN`。
- **`MATNR` 不能补零** —— 为 `CHAR40` 且主数据存不补零形态，补零反而取不到。要用 `CONVERSION_EXIT_MATN1_INPUT`。

```abap
" 对
CALL FUNCTION 'CONVERSION_EXIT_MATN1_INPUT'
  EXPORTING input  = lv_matnr
  IMPORTING output = lv_matnr.
```

## 3. 金额 / 日期 / 数值

- **金额字段**：BAPI 的 `AMT_DOCCUR` 等建议**直接赋字符串常量**（`'1000.00'`），避免 `WRITE ... DECIMALS` 带入千分位。
- **过账日期字段是 `PSTNG_DATE`**，不是 `POSTING_DATE`。
- **借贷符号**：FI BAPI 用「借正贷负」；走封装接口时通常按 `BSCHL` 查 `TBSL-SHKZG` 反推方向，**金额一律传正数**，记账码给错就报「记账码不存在」。
- **探针入参为数值型（`DEC`）必须用数值字面量赋值**，赋字符串报 `cannot be interpreted as a number` 并返 500。

### 3.1 13 位毫秒时间戳

- **直接转 `TIMESTAMP` 会得到 `00000000`**：毫秒除 1000 得 10 位秒数赋 `CHAR14` 后右对齐左补空格，`CONVERT TIME STAMP` 视为非法而失败且不报错。
- 正确做法：截前 10 位 + `cl_abap_tstmp=>add( )`。该 FM 的 `TSTMP` 形参要求 `TIMESTAMP` 类型，**直接传字面量抛 `CX_PARAMETER_INVALID_TYPE`**。

### 3.2 `CONCATENATE` 拼 `NUMC3` 会保留前导零

`'009'` 拼成 9 位字符串赋 `DATS(8)` 被截，月末算成 `0001-01-31`。用偏移量 `p_perio+1(2)` 跳过前导零。

## 4. 字符比较与清理

- 字符字段比较前先 `CONDENSE ... NO-GAPS`，否则前后空格导致「明明相等却不进 IF」。
- 长文本/大字段跨系统传递时注意尾部空格：`CHAR` 型 `=` 赋值不裁尾，但写库/写文件会裁。
- 拼 KEY 用 `|` 拼接而非 `CONCATENATE`，避免类型转换意外（`CONCATENATE` 对 `NUMC` 会保留前导零，见 §3.2）。
